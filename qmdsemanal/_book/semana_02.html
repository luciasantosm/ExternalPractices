SMURF

One of the doubts that I had about SMURF is the third input explained in the SMURF manual, ‘segmentation_final.npy’. As indicated it is generated by performing your own segmentation over so.image_temp(), resulting in a NumPy array with the shape as so.image_temp().

I think the .npy file comes from StarDist segmentation –> I’m not sure of this beacuse in the documentation they don’t mention explicitly the outputs, although they mention:

“The image annotations (also known as label images or label masks) should be integer-valued (e.g. 8-bit, 16-bit, 32-bit) TIFF files where all background pixels have value 0 and each object instance is represented by an area/volume filled with a unique positive integer value. It does not matter what the values are and they do not need to be consecutive. Please note that a foreground/background segmentation mask, where all object instances are denoted by the same value, is not sufficient for StarDist training.”

I think this is basicly what SMURF needs.

SpaceRanger does not generate any NumPy array, the only file that could supply this input is the nucleus_instance_mask.tiff. So, I searched how to convert a tiff file to a numpy array and I found the following code:

import tifffile

tiff_image = tiff.imread('smurf_segmentation/outs/nucleus_instance_mask.tiff')
array_image = np.array(tiff_image)

Now I have to check if effectively the .tiff file generated by SpaceRanger is compatible with the input of SMURF.
